## Reply Handling Playbook

### If Investor Replies with Interest
1. Reply within 2 hours (same day max)
2. Send Calendly link or propose 3 specific time slots
3. Prepare 10-slide deck for the call
4. Have metrics dashboard ready (live MRR, user growth, device count)

### If Investor Asks for More Info
1. Send pitch deck PDF within 24 hours
2. Include product demo video (2-3 min)
3. Attach cap table and SAFE terms
4. Offer reference calls with existing users

### If Investor Passes
1. Thank them for the quick response
2. Ask for feedback (why not a fit?)
3. Request they keep you in mind for future rounds
4. Add them to quarterly update list
